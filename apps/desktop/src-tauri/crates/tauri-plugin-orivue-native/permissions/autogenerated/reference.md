## Default Permission

Reproductor nativo, botón atrás e información del dispositivo

#### This default permission set includes the following:

- `allow-load`
- `allow-stop`
- `allow-set-paused`
- `allow-set-volume`
- `allow-set-aspect`
- `allow-seek`
- `allow-select-track`
- `allow-get-tracks`
- `allow-set-back-handling`
- `allow-get-device-info`
- `allow-exit-app`
- `allow-register-listener`
- `allow-remove-listener`
